# 김다조이의 구구단 모험 🌈

8세 아동을 위한 교육심리학 기반 구구단 학습 게임 (Android 태블릿/폰)

## 게임 소개

**별빛 군단 러너** — 수학 마법사 **김다조이**가 군단을 이끌고 달리며 곱셈 게이트를
통과한다. `7 × 8` 게이트엔 7열×8행의 별이 빛나고, 세 개의 문 중 **맞는 답의 문**으로
달려들면 56개의 별가루가 터지며 군단이 불어난다. 틀려도 죽지 않는다.

> **설계 철학**: 곱셈을 "보상을 받기 위한 시험"으로 두지 않는다. 곱셈은 군단을 불리는
> **게임의 물리 법칙**이다 — 잘 알수록 게임을 더 잘하게 된다(내재적 통합, Habgood &
> Ainsworth 2011, *Zombie Division* 연구). 이전의 "문제풀이 + 보상" 구조를 버리고
> 곱셈이 곧 메커니즘인 단일 게임으로 다시 설계했다.

## 적용된 학습 과학

| 이론 | 적용 |
|------|------|
| 내재적 통합 (Intrinsic Integration) | 곱셈 = 군단을 불리는 게임 메커니즘 (퀴즈 아님) |
| 배열/넓이 모델 | 게이트마다 a열×b행 점 배열로 곱셈을 시각화 |
| 간격 반복 (SM-2, 아동용 조정) | 어떤 곱셈이 게이트로 나올지 SM-2 두뇌가 선택 — 초기 간격 1→2→3일 |
| 교환법칙 페어링 | 3×7 = 7×3 한 카드로 — 외울 분량 72개 → 36개 |
| 난이도 기반 해금 순서 | 2 → 5 → 3 → 4 → 9 → 6 → 7 → 8단 (해금된 단만 게이트 등장) |
| 무(無)시간압박 | 카운트다운 없음 — 문 앞에서 기다려 줌 (수학 불안 방지, Boaler 연구) |
| 무패널티 오답 (no-fail) | 틀리면 잠깐 멈춰 정답을 보여줄 뿐, 절대 실패·죽음 없음 |
| 가변 비율 강화 | 룰렛 보상 — 예측 불가능해 내재적 동기를 해치지 않음 |

## 보상 시스템

- **룰렛**: 단 마스터 / 완벽한 질주(전부 정답) / 7일 연속 달리기 시 티켓 획득. 꽝 50% / 100원 40% / 1000원 10%
- **저금통**: 당첨금 누적 → 부모가 실제 현금으로 전달
- **별 조각**: 정답 수만큼 지급 — 캐릭터 꾸미기 화폐 (홈에서 김다조이를 탭하면 상점)
- **군단**: 정답마다 트레일이 길어지는 즉각적 시각 피드백

│   ├── progression.dart       # 숙달/해금 판정
│   └── roulette.dart          # 확률 보상
├── screens/                   # 홈, 러너(핵심 게임), 결과, 룰렛, 상점, 부모 리포트

## 로드맵

- **Phase 1**: 핵심 학습 루프 + 룰렛 + 저금통 ✅
- **Phase 2**: 캐릭터 꾸미기 상점 + 별 수집 모드 ✅
- **Phase 3**: Firebase 기기 간 동기화(가족 코드), 부모 리포트, TTS ✅
- **Phase 4 (게임성 재설계)**: "문제풀이+보상" → **크라우드 러너**로 전환 — 곱셈을
  게임 메커니즘에 내재화, 8개 모드의 복잡함 제거, 단일 핵심 게임에 집중 ✅
  - 제거: 세계 지도, 4지선다/숫자패드 퀴즈 화면, 별 수집 모드
  - 유지·재활용: 김다조이 캐릭터, SM-2 두뇌, 해금 순서, 룰렛/저금통, TTS, 부모 리포트, 동기화

## Phase 3 기능

- **TTS 암송**: 새 마법(카드)을 배울 때 "이 삼은 육"을 한국어 음성으로 낭독
- **부모 리포트**: 홈 화면 "레벨 N 수학 마법사" 글씨를 3번 탭 → 4자리 PIN 설정/입력
  - 30일 출석 달력, 단별 정답률 차트, 저금통 잔액·당첨 내역, 지급 완료(초기화) 버튼
- **기기 동기화 (태블릿 ↔ 폰)**:
  1. 기기 A: 부모 리포트 → 기기 동기화 → "새 코드 생성" → 6자리 코드 확인
  2. 기기 B: 같은 메뉴에서 그 코드 입력 → "코드 연결"
  3. 이후 앱 시작 시 자동 동기화 + "지금 동기화" 버튼으로 수동 동기화
  - 병합 규칙: 별/저금통은 기기별 적립분 합산(3-way), 스트릭·최고점수는 max,
    출석·숙달·소장품은 합집합, 카드 학습 상태는 더 많이 진행한 기기 우선

### 러너 설계 노트

- **시간 압박 없음**: 게이트는 결정선까지 내려온 뒤 입력을 무한히 기다린다. 달리는
  연출은 있지만 카운트다운은 없어 수학 불안을 유발하지 않는다.
- **no-fail**: 틀려도 게임 오버가 없다. 군단이 살짝 줄고 정답을 보여준 뒤 계속 달린다.
  (틀린 곱셈은 TTS로 한 번 더 들려줘 부호화를 돕는다.)
- **곱셈은 항상 구구단 범위**: 게이트마다 2~9 × 2~9 사실 하나가 독립적으로 출제되므로
  Count Masters식 "군단×배수"가 구구단을 벗어나는 문제를 피한다. 군단 트레일은 콤보
  연출(시각 보상)이고, 실제 학습은 게이트의 곱셈 사실이 담당한다.
- **SM-2 반영**: 한 번의 달리기에서 각 사실의 **첫 등장**만 SM-2에 반영한다(중복 방지).
